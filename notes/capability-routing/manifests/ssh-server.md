# SSH Server

仅用于：连接 <server-ip> 执行服务器运维（部署、服务管理、日志查看），执行前必须确认。
不要用于：未经确认的远程命令、自动 SSH、非运维目的的远程访问。

## 基本信息

- **能力 ID:** ssh-server
- **名称:** SSH 服务器运维
- **类型:** CLI
- **平台:** 共享
- **来源:** SSH 密钥 `~/.ssh/id_ed25519`
- **能力槽:** SSH 连接远程服务器，执行命令/部署/服务管理

## 存储决策

- **资产管理:** cli
- **管理状态:** active
- **健康状态:** healthy
- **风险:** high（root 访问、公网服务器）

## 路由

- **触发条件:** 服务器部署、服务重启、配置更新、远程日志
- **禁用条件:** 未经用户确认不得执行任何远程命令
- **替代方案:** 无（唯一服务器入口）
- **Registry 条目:** `registry/level2-registry.md#ssh-server`

## 连接信息

- **服务器:** `<server-ip>`（root, SSH 端口 `<ssh-port>`）
- **仓库路径:** `<server-project-path>`
- **服务:** `<gateway-service>`（user unit）
- **到期:** 2027-03-31

## 安全

- **权限范围:** 服务器 root 完全访问
- **是否涉及凭据:** 是（SSH 私钥）
- **副作用:** 可重启服务、修改文件、执行任意命令
